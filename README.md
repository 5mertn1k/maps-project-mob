# Приложение с картой (React Native + Expo)

Мобильное приложение, где можно ставить маркеры на карте и прикреплять к ним изображения.

## Установка и запуск

1. Установите Node.js (LTS) и приложение Expo Go на телефон.
2. Склонируйте репозиторий и установите зависимости:

```bash
git clone <ссылка-на-ваш-репозиторий>
cd <папка-проекта>
npm install
```

3. Запустите проект:

```bash
npx expo start
```

4. Отсканируйте QR-код в Expo Go (телефон и компьютер должны быть в одной сети).

Проект использует Expo SDK 52.

## Возможности

- Карта на весь экран, маркер добавляется долгим нажатием
- Нажатие на маркер открывает экран с деталями
- Список изображений маркера, добавление из галереи и удаление
- Обработка ошибок: загрузка карты, выбор изображений, навигация

## Структура проекта

```
app/
  _layout.tsx        корневой layout, подключает MarkerProvider
  index.tsx          экран карты
  marker/[id].tsx    экран деталей маркера
components/
  Map.tsx            карта (WebView + Leaflet)
  ImageList.tsx      сетка изображений с удалением и предпросмотром
context/
  MarkerContext.tsx  общее хранилище маркеров и изображений
types.ts             интерфейсы TypeScript
```

## Принятые решения

- **Навигация:** Expo Router (файловая маршрутизация). Экран деталей получает `id` маркера из адреса `/marker/[id]`.
- **Состояние:** React Context. Маркеры и их изображения хранятся в одном месте, и оба экрана работают с одними данными.
- **Карта:** вместо `react-native-maps` использована связка `react-native-webview` + Leaflet + плитки OpenStreetMap. Нативная карта в Expo Go на тестовом устройстве отображалась пустой (плитки не рисовались), поэтому выбрана альтернатива OpenStreetMap, рекомендованная преподавателем. Обмен данными между картой и приложением идёт через `postMessage`.
- **Изображения:** `expo-image-picker` с запросом разрешения на доступ к галерее.
- **Типы:** `MarkerData`, `ImageData`, `MarkerRouteParams` описаны в `types.ts`.

## Дополнительные функции

- Предпросмотр изображения на весь экран по нажатию
- Подтверждение перед удалением изображения
- Индикатор загрузки карты и экран ошибки с кнопкой «Повторить»
- Экран «Маркер не найден», если маркер отсутствует

## Известные проблемы и ограничения

- Для работы карты нужен интернет (Leaflet и плитки загружаются из сети).
- Данные хранятся только в памяти и пропадают при перезапуске приложения.
- Удаление изображения убирает только запись из списка, файл остаётся в кэше приложения.
- Приложение проверялось только на Android через Expo Go.
